# 拼图 · 在线图片拼接

纯前端的在线拼图工具（React + Vite + TypeScript），没有后端，图片只在浏览器本地处理，可以直接部署到 Vercel。手机和电脑浏览器都能用。

## 功能

- 一次选择多张图片（最多 20 张），电脑上也可以直接把图片拖进页面
- 「留白」布局（1～3 张）：杂志式排版，图片按原比例摆放、周围留白，支持贴边出血、错位、叠放描边；横版画布自动改为左右排
- 按张数自动给出多种拼接布局：1 到 9 张有精选布局（含上小下大、左窄右宽、交错、中间大图两边小图等），更多张数自动生成
- 画布比例：1:1、4:5、3:4、2:3、3:5（小红书全屏）、9:16、3:2、4:3、16:9
- **拆成多张（轮播无缝拼图）**：横向拆成 2～5 张，画面左右连在一起，适合 Ins / 小红书左右滑动。
  例如一张图拆成左右两半，或 3 张图拆成 2 张（每张里各有一张半图）。导出时自动生成每一页，可以一次分享 / 全部下载
- **完整显示 · 补背景**：照片不裁切、按原比例完整放进格子，空出的地方用背景色补齐（比如 2:3 竖图放进 1:1，左右自动补白）。
  可以在「比例」里全局切换，也可以选中某一张单独切换；完整显示时仍可拖动调整照片在空白里的位置，也可以放大
- 调节间距、外框、圆角、背景颜色
- 每格图片单指拖动调整画面，双指或滚轮缩放
- 轻点选中图片后可以换位、替换、复位、删除
- 导出：标准 / 高清 / 超清三档尺寸，JPG（95% 质量）或 PNG（无损）
- 手机上支持系统分享（可直接存到相册），也可以长按结果图保存

## 画质说明

- 编辑时用的是缩小后的预览图，导出时会重新读取**原图**，逐级缩放后绘制，画质不受预览影响
- 手机照片的 EXIF 方向会自动校正
- 最大导出约 1600 万像素（iOS Safari 的画布上限）

## 本地运行

需要 Node.js 20 或以上。

```bash
npm install
npm run dev
```

`npm run dev` 带了 `--host`，手机和电脑连同一个 Wi-Fi 时，用终端里显示的局域网地址就能在手机上调试。

## 部署到 Vercel

**方式一：通过 GitHub（推荐）**

1. 把这个文件夹推到一个 GitHub 仓库
2. 在 vercel.com 点 “Add New → Project”，导入这个仓库
3. Vercel 会自动识别为 Vite 项目（构建命令 `npm run build`，输出目录 `dist`），直接点 Deploy

之后每次 push，Vercel 都会自动重新部署。

**方式二：命令行**

```bash
npx vercel        # 预览部署
npx vercel --prod # 正式部署
```

## 代码结构

```
src/
  App.tsx                 主界面与状态
  layouts.ts              布局模板（用 "r:1,2/2,1" 这类简写定义，方便自己加）
  geometry.ts             格子与图片位置计算（预览和导出共用，保证一致）
  exporter.ts             Canvas 合成与导出
  imageLoader.ts          读取图片、生成预览
  components/Board.tsx    画布与触控手势
  components/ExportSheet  导出面板
```

### 添加新布局

在 `src/layouts.ts` 的 `SPECS` 里加一行简写，例如：

- `'r:1,2'`：两行，第一行 1 张、第二行 2 张
- `'r:1,1/1,2'`：两行各 1 张，上面占 1/3、下面占 2/3（上小下大）
- `'c:1,3/2,1'`：两列，左边 1 张占 2/3 宽，右边 3 张竖排

更复杂的嵌套布局写在 `NESTED` 里，用 `H(...)`（左右并排）、`V(...)`（上下堆叠）、`L`（一张图）组合，
`[权重, 节点]` 指定相对大小，例如 `H([2, L], [1, V(L, L)])` = 左边大图、右边上下两张。

拆成多张时，布局会按"格子不要太细长、画面跨过分页线"重新排序，并额外生成按列分组的布局。
